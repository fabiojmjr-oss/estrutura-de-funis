# Security / Segurança

**EN —** This repository holds no secrets and no real data (see [`DISCLAIMER.md`](DISCLAIMER.md)).
The published page is static: it loads nothing from third parties, sets a Content Security Policy
that only allows its own origin, and treats every value in a shared link as untrusted text. If you
find a way to make a link run code or leak data, please report it privately through the
repository's **Security → Report a vulnerability** form rather than in a public issue.

**PT —** Este repositório não guarda segredos nem dados reais (ver [`DISCLAIMER.md`](DISCLAIMER.md)).
A página publicada é estática: não carrega nada de terceiros, define uma política de segurança de
conteúdo (CSP) que só permite a própria origem e trata todo valor de um link compartilhado como texto
não confiável. Se encontrar um jeito de um link executar código ou vazar dados, reporte em privado
pelo formulário **Security → Report a vulnerability** do repositório, e não numa issue pública.
